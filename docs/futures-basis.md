# 현선물 가정 연구 API

`POST /api/research/basis-analysis`는 `research/basis.py`의 `cash-futures-1` 엔진을 호출한다.
기존 읽기 전용 API와 같은 LAN·토큰 정책과 출처 검사를 적용한다. 계산에는 연구 작업 슬롯을
공유하며 파일·계좌·주문을 변경하지 않는다. JSON은 최대 500KB이고 중복 키·NaN을 거절한다.

입력은 `{mode:"scenario",config:{...},scenario:{...},source_note:"가정"}` 또는
`{mode:"replay",config:{...},quotes:[...],source_note:"출처"}`다.
스키마는 `BasisConfig`, `Scenario`, `Quote`, `BasisRequest`에 정의한다.
시나리오의 가격·비용은 실제 시세가 아니다. 호가 재생도 원천 대조 전이며 항상
`source_verified=false`, `live_eligible=false`, `orders_sent=0`을 반환한다.

현물 매수/선물 매도와 대차 확보 조건의 역방향을 지원한다. 기준 투자금·정수 계약·
양쪽 호가 수량·대차 수량을 제한하고, 다음 호가에서 재검증 후 양쪽 체결을 가정한다.
단일 계약 한 번의 진입과 목표 이익·손실 한도·증거금·회수·만기·기간말 청산을 재생한다.
실제 주문 상태 머신이나 한쪽만 체결된 계좌의 복구는 별도 구현 대상이다.

표준 개별주식 10주, KOSPI200 250000/미니 50000 승수를 허용한다. 현물은 원가격이어야 하며
계약별 권리조정·휴장일·호가단위 검증 전이다. ETF 잔여 노출·추적 차이를 위험으로 표시한다.
현물 평가이익을 즉시 증거금 현금으로 쓰지 않는다. 최종정산가격은 마감 후에만 허용하며,
현물 처분 호가가 없는 경우 최종 가상 손익을 확정하지 않는다.

반환 결과는 원본 입력 해시, 정규화 설정, 시나리오별 이벤트·손익·현금·증거금 원장,
추가 자금·일시적 미헤지 1% 손실 규모, 재생용 전체 JSON, 결과 해시를 포함한다.
금융비용은 현물 전액·개시증거금 단리 기회비용이다. 추가 증거금 조달비용·실제 결제일
현금 잠김·투자자별 최종 세금은 제외한다. 결과의 limitations를 소비 화면에 표시해야 한다.
